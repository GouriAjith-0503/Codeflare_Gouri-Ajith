## 🌟 Project Overview

**Veilweave** is an interactive, responsive mythological exploration and creative storytelling platform uniting seven sacred civilizations: **Indian, Greek, Egyptian, Norse, Aztec, Chinese, and Japanese**.

Veilweave provides:
1. **Educational Architecture of Memory**: A dedicated Home page showcase exploring what **Mythology** (cosmic architecture, divine law, existential origins) and **Folklore** (hearthside living soul, human resilience, communal wisdom) mean, and how civilizations weave both.
2. **Illuminated Stories of World Civilizations**: Authentic sacred mythologies explaining how each civilization's mythology and folklore came to be, paired with living, moving animated artwork styled with culturally specific motifs.
3. **Cultural Theme Matrix**: Dynamic CSS variable injection (`--primary-color`, `--secondary-color`, `--border-style`, `--bg-pattern`) on mythology selection, featuring rotating mandalas, glowing diyas, fluted pillar borders, wave pulses, rune shimmer, snow drifts, golden pulses, stepped pyramid frames, sakura drifts, and scroll unfolds.
4. **Progressive Multi-Level Trial Grounds**: A 10-level memory match game where tile counts expand across rounds (6 → 36 tiles) alongside a 15-second timed mythological trivia quiz.
5. **Legendary Creature Crosswords**: A digital interactive and pen-and-paper printable crossword activity themed around global cryptids, deities, and legendary beasts.
6. **Mythos Spark (Creative Story Forge)**: An interactive prompt generator allowing users to combine divine archetypes, ancient elements, and cosmic dilemmas to ignite original stories.
